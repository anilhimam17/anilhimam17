## What's Next for Parc Fermé

The project is moving from high-level race debriefing toward deeper performance modelling:

- **Race strategy:** undercut/overcut battles and strategic decision-making.
- **Track evolution:** quantifying how circuit conditions affect pace across sessions.
- **Telemetry:** synchronised FastF1 channels through Mark-1 for downstream analysis.
- **Weather:** linking conditions with pace, cooling and tyre behaviour.
- **State-space modelling:** treating competitor and vehicle performance as evolving latent states.
- **Race simulation:** exploring plausible race futures with simulation and reinforcement learning.
- **Multimodal analysis:** mapping telemetry to onboard footage for driver and chassis analysis.
- **Physics-informed modelling:** exploring ERS deployment, ICE variables and aero/cooling trade-offs.
- **Motorsport history:** applying the same analytical framework across different generations of F1 cars where meaningful data is available.

The aim is to build a **proper race debrief and performance analysis system** — deep enough for racing enthusiasts and data nerds, while accessible enough to help new fans understand the engineering behind the sport.
